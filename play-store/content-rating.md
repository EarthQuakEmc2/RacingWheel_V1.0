# Content rating notes

Fill the Play Console content-rating questionnaire (IARC) from these answers. The app is a game controller. It does not contain a game.

| Topic | Answer |
| --- | --- |
| Category | Utility, or app that is not a game. If the console forces a game category, it is a racing utility with no depicted violence. |
| Violence | None. No blood, no weapons, no realistic or cartoon violence. |
| Sexuality | None. |
| Language | None. No profanity in the UI. |
| Controlled substances | None. |
| Gambling | None. No simulated gambling, no loot boxes, no real-money contests. The only purchase is a one-time unlock of wheel layouts. |
| User interaction | Users do not communicate with other users inside the app. No chat, no public profile, no user-generated content that is shared. |
| Unrestricted web | The app does not open a web browser and does not embed web content. |
| Location sharing | The app does not share the user's location with other users. |
| Digital purchases | Yes, on the Play build: one in-app product, `racing_wheel_premium`, $3.99, non-consumable. No random items. |
| Target age | Everyone. The controller can be used with games that have their own ratings. This app does not depict those games. |

Expected results, if the questionnaire matches the answers above: ESRB Everyone, PEGI 3, USK 0, IARC 3+. Confirm the certificate the console generates before you submit. Do not claim a rating the certificate does not show.

The store listing must not use car-maker or wheel-maker names. See PUBLISHING.md. A mismatch between the listing text and the screenshots is a common rejection, separate from the age rating.
